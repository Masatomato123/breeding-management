# 繁殖巡回 記録・閲覧 PWA

酪農場の繁殖検診をスマホ単体で記録・閲覧するオフライン対応アプリです。
データは端末内（IndexedDB）にのみ保存され、外部には一切送信されません。

## ファイル構成
- `index.html` … アプリ本体（HTML/CSS/JS すべて同梱）
- `manifest.json` … PWA設定（ホーム画面への追加用）
- `sw.js` … Service Worker（オフライン起動用）
- `icon-192.png` / `icon-512.png` / `icon-maskable-512.png` / `icon-180.png` … アイコン

**7ファイルすべてを同じフォルダに置いてください。**

## GitHub Pages への公開手順
1. GitHub でリポジトリを新規作成（例：`hanshoku`）。
2. 上記7ファイルをリポジトリ直下にアップロード（ドラッグ＆ドロップで可）。
3. リポジトリの **Settings → Pages** を開く。
4. 「Build and deployment」の Source を **Deploy from a branch**、Branch を **main / (root)** にして Save。
5. 1〜2分後に表示される `https://<ユーザー名>.github.io/hanshoku/` を開く。
6. スマホのブラウザで開き、**共有 → ホーム画面に追加**（iOS）／メニュー →**アプリをインストール**（Android）。

> HTTPS が必要なため、PWAのインストールとオフライン動作には GitHub Pages（無料HTTPS）等の公開が必須です。
> claude.ai のプレビュー内では IndexedDB が永続しないため、動作確認は必ず公開URLで行ってください。

## 使い方の要点
1. 初回は **農場を追加**（農場ごとに VWP・授精開始日齢などを設定）。
2. **牛を登録**（未経産JMRのため生年月日は必須）。
3. 個体カルテやリストから **イベントを1件ずつ記録**（分娩／授精／妊鑑／検診所見／乾乳）。
4. **未授精リスト・妊鑑リスト**は農場の閾値どおり自動生成。リスト上で所見も入力可。
5. **JMR月別推移**（PNG書き出し可）と **KPIダッシュボード**で群の成績を確認。
6. **データ画面**から CSV／画像／印刷、および JSON バックアップ・復元。

## 重要：バックアップ
iOS はストレージを破棄することがあります。**データ画面から定期的に JSON バックアップ**を保存してください。
機種変更時も、JSON を書き出して新端末で読み込めば全データを移せます。

## KPI 定義について
繁殖成績KPI（受胎率・空胎日数・発情発見率など）は近似・仮定を含みます（アプリ内に注記あり、コード内にコメント）。
運用前に定義をご確認・調整ください。旧Excelの「結果」シートは日付シリアル値の混入で異常値が出ていたため、本アプリは定義から計算し直しています。
